# 实验协议 protocol.md（P2 · R1，2026-09-11）

## 研究问题 / 假设（可证伪，冻结于运行前）

- **H1**：同一总花费下，五轴**统一**预算分配的任务成功率 > 推理预算与 agent 预算**分立**。
  证伪：解耦以 ≤ 成本达到给定成功率。
- **H2**：跨轴自由调剂 > 均匀加码（每个轴一起拉大）。
  证伪：均匀基线与统一路由在匹配成功后/成本上不劣。
- **H3**：最优分配**构成**随预算改变，而非等比放大。
  证伪：最优各轴水平随预算近共单调。
- **H4（已执行，2026-09-24）**：真实 LLM（Qwen3-8B-AWQ / Qwen3-14B-AWQ，vLLM，温度 0）下的 agent 轴增益实测已完成，两臂各 672 集（iso 240 + axis_steps 120 + axis_tools 168 + axis_vision 144，repeats=3）。产物 `results/h4_real_llm_gx_qwen3_8b_persist.json`、`results/h4_real_llm_gx_qwen3_14b_persist.json`；读数与判据在 `CLAIM_LEDGER.md` C39-C49。**登记的结论是「增益不可引用」**：三轴 bootstrap CI 宽度 1.00/1.00/0.58 全部超过本文件下方分析计划设定的 0.30 上限（`experiments/h4_derived_stats.py:153-154`），因此 g_x 数值不得进入正文，「算力受限 vs 精度受限」分类在本实验下不可得。

## 分析计划

- 统计口径：所有延迟聚合由唯一脚本 `analysis.py` 从 `results/*.json` 的**逐次原始样本**
  重算，并 `assert` 与落盘聚合一致（`recompute_checks_passed` 必须为 true）。
- 置信区间：4000 次 bootstrap（百分位法，α=0.05），n_boot 与 seed 写入产出 JSON。
- E2 的匹配比较用**双口径**：(a) 在基线自身成本处的最大成功率；(b) 达基线成功率的最小成本。
  两者都必须在正文出现，禁止只报有利的那一侧（FIX-02 教训）。
- 多重比较：E2 的敏感性网格为 30 点探索性扫描，不做显著性声明，只报区间与反转例数。
- 无 p 值声明：本工作不做假设检验型结论；H1/H2/H3 以确定性优化结果 + 敏感性区间判定。

## A9 · 增益可辨识性的扩样重复（运行前登记，2026-09-24 02:59Z）

**动机（一手）**：H4 现测三轴 CI 宽度 1.00 / 1.00 / 0.58，全部超过 0.30 的预登记上限，
所以「增益取不到值」目前只是**精度问题未排除**：现有 axis 臂每设置 3 次重复（axis 共 432 集）。

**唯一改动**：axis 臂重复数 3 → 12（`--arms axis_steps,axis_tools,axis_vision --repeats 12`，
1,728 集），模型/任务集/两个动作菜单/每集的 (task, menu, level, setting) 组合/种子派生方式
全部沿用（种子由单元索引与 rep 序号决定，因此 3 次重复是 12 次的前 3 次，属**同一母体的扩样**，
不是新总体）。iso 臂不跑：增益拟合按实现只读 axis 臂（`h4_real_llm_gx.py` 内 `# fit on the axis arms only`）。

**主要判据（跑之前定死，与现有实现同一式）**：每轴 `ci95_width <= 0.30` 才算可引用，
阈值与算法取 `experiments/h4_derived_stats.py:153-154`（`withheld = w > 0.30`），不改常数、不换估计量。

**决策规则（预先声明）**：
1. 若 ≥1 轴的宽度降到 0.30 以下 ⇒ 该轴 g_x 可引用，正文只引用**通过的那几轴**，其余继续 withheld；
2. 若三轴仍全部 > 0.30 ⇒ 判「在本任务的分辨率下增益不可辨识」，并**停止加样**（不再第三次扩样），
   把结论改写成精度上界而非点估计；
3. 若扩样后点估计与 repeats=3 的读数差超过该 3 次重复自身的 CI 半宽 ⇒ 记录为**不稳定**，
   该轴即使宽度达标也不引用（防把采样噪声当结论）。

**范围声明**：本扩样只为提高 g_x 的可辨识性，**不**用于检验 iso 曲线形状或跨规模反转
（C46/C47 那些结论的样本不变；若拿本数据重述形状结论即属事后加戏，禁止）。

**成本与载体**：单臂实测吞吐 672 集 / 1754.5 s（8B, `results/h4_real_llm_gx_qwen3_8b_persist.json`
的 `timing`）⇒ axis 子集 1,728 集预计 ≈ 4.5×10³ s（约 1.3 h），锁内执行，产物落
`/root/autodl-tmp/cont_d0788aa9/h4_a9_8b/results/`，运行前 SHA 必须是 `3326b513fa89…`（同码臂，
否则与本表 C49 的配对关系断裂即拒跑）。



## A9 附录 · 读取路径更正（写在判读之前：2026-09-24 05:10Z）

**发生了什么**：A9 产物落盘后按注册路径判读，`experiments/h4_derived_stats.py` 在其 iso 描述段
`actions[L] = {a: c.get(a, 0) / len(rs) ...}` 处 `ZeroDivisionError`（rs 为空），判读器 rc=3 ⇒
**判据本身没被执行**。原因不是数据坏，是设计使然：A9 只复制三条轴臂、`iso` 一条不入本臂，
所以产物里 `arm == "iso"` 的记录数为 0，而生产者的描述段全部建在 iso 之上。

**改了什么（只动读取路径，一条判据没动）**：
① 把可辨识性算式抽成 `identifiability_from(fit)`，两条出口共用一份公式（复制一份就会有两份可漂移）；
② 新增 axis-only 分支 `write_axis_only`：iso 描述段一律写成**显式 NOT_RUN 标记**，而不是 0 或空 dict
（空 curve 落在 `results/` 里会被读成"测了个空"）；
③ 阈值改成单点定义 `MAX_CI_WIDTH = 0.30`（现值在 line 90，`withheld` 公式在 line 107 引用它），
原先两处字面量各写一遍；0.30 的取值与 `withheld = w > 0.30` 的式子一字未改。

**回归证明（补丁必须对既有臂行为保持）**：对含 iso 的注册产物
`results/h4_real_llm_gx_qwen3_8b_persist.json` 跑改前/改后两次，输出**字节相同**
（两侧 sha256 前缀 a5c93b1adf36ace9、4073 B）。备份 `experiments/h4_derived_stats.py.bak_noiso_20260924T050652Z`。

**没改什么**：臂的设计（三轴 × 12 repeats = 1728 episodes、模型/任务/菜单/种子派生不变）、A9 三条预声明规则、
产物本身（本地副本 1,648,561 B、sha 前缀 4e6b86a4519b872d；跨机四账：字节等 + 双侧 sha + 落盘后重读 + JSON 可解析）。

**由此产生的限制（写进结论边界）**：axis-only 分支不产出 iso 描述量 ⇒ **本臂不得用于任何 iso、
非单调性或 McNemar 陈述**；这类读数只能引用注册产物（repeats=3）那份。A9 §范围禁令原已含此意，
这里补一句是因为读路径本身现在有了两条出口，读者需要知道这条出口少了什么。
