# Related Work — 可控制测试时计算 / 预算感知智能体的先行对照

> 本文件把 agent-effort-r1 与**真实存在的先行工作**对照。所有引用均来自 `paper/main.bib`（8 条真实文献）。
> **关键边界**：本仓库**不声称**首个统一智能体成本、也不声称发现「预算感知 ≠ 经济行为」——
> 它的独特材料是**这个小任务套件的核算与协议审计**。

## 4. 相对先行的定位与边界

- **独特材料**：本仓库做的是**这个小任务套件**（8 个手工任务）的**核算与协议审计**，不是新基准或新统一度量。
- **不声称**：①不声称首个统一智能体成本；②不声称「预算感知 ≠ 经济行为」是首发现；③不声称 E2 是部署前沿。
- **主要局限**：E2 的收益/token 价格/无约束动作组合是**假定**，不是实测部署收益；网格把坐标当独立可分配，
  无动作依赖约束（`(100,1,16,16,16)` 不是可行 H4 轨迹）。

## 5. 一句话定位

> 相对「可控制测试时计算」的既有研究（综述、Self-Consistency、CoBa、Beam Search），本仓库不新增统一度量；
> 相对「预算感知智能体」（Budget-Aware Tool Use、EcoAgent-Bench），本仓库不声称首个发现；
> 它的增量是**把一个小任务套件的核算与协议审计做完整、可复现**，并**明确区分测量与假定**。
