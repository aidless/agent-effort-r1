`CLAIM_LEDGER.md` points at as evidence, copied verbatim, except the one
`source_result` redaction recorded below. Nothing else here was selected by hand.

The `paper/` sources are shipped at the top level as usual; these paths keep their
relative positions so a ledger pointer of the form `results/x.json -> field` can be
followed inside the package as `anc/results/x.json`.
